How It Works

Asset Release combines a selected part-number template with date values from an ingested asset table.

DataLoad and inspect asset records.
TemplateCreate one comment template per P/N.
CommentFind an asset and generate its comment.

Data Route

Upload an .xlsx, .xls, or .csv file, or paste table data. For Excel workbooks, the first worksheet is imported.

Recommended headers

part number,serial number,DOM,HST
M03048-01,LH1175,1/7/23,1/2/23

Common header variants such as part, part no, serial, and date of manufacture are accepted.

Preview and sorting

Rows are normalized and sorted by Part Number, then Serial Number. Header filters narrow the visible preview without deleting lookup data.

Date interpretation

The importer accepts month/year, ISO dates, full numeric dates, short-year dates such as 1/7/23, and Excel date serial values.

Canonical output: DOM, life expiry, HST, and next HST use MM/YYYY. Next maintenance uses DD/MM/YYYY.

Template Route

  1. Open Template.
  2. Select a P/N, or enter a new P/N and click Add part number.
  3. Edit the wording for that P/N.
  4. Keep date placeholders where data should be inserted.
  5. Click Save template.

Supported date placeholders:

{{dom}}
{{hst}}
{{lifeExpiry}}
{{nextHst}}
{{nextMaintenanceDue}}

Only date placeholders are replaced automatically. The rest of the template wording remains unchanged.

Comment Route

  1. Load data on the Data route.
  2. Select a P/N or enter a unique serial number.
  3. If the serial is unique, the matching P/N and template are selected automatically.
  4. If it exists under multiple P/Ns, select the P/N first.
  5. Click Generate comment.
  6. Copy the result or click Print.
Life expiry      = DOM + 15 years
Next HST         = HST + 5 years
Maintenance due  = earlier of life expiry and next HST

P/N and serial matching ignores letter case, spaces, hyphens, slashes, and other punctuation.

Data Privacy

Asset data is processed in the browser only. The browser reads the file, SheetJS converts the worksheet, and all normalization, sorting, lookup, date calculation, and comment generation run locally.

Uploaded asset data is not sent to an ENG360 server or Supabase. It remains in page memory and is cleared when the page is refreshed or closed. Saved templates use browser local storage.

Troubleshooting

No matching asset

Load data first, confirm the serial appears in the preview, select the P/N if the serial is duplicated, and confirm DOM/HST values exist.

Invalid date

Use a supported date format. Consolidated tables using values such as 1/7/23 are accepted and displayed as 01/2023.

Excel file not loading

Use an .xlsx, .xls, or .csv file with headers in the first row and records on the first worksheet.
